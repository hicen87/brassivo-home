# EPS 加权评分与分市场排序

## 目标

在公开 EPS 看板中为每只股票显示 0–100 分，并在 US、A、HK 各市场内部按分数降序排列，禁止跨市场混排。

## 评分口径

- 模块权重：Magnitude 40%、Agreement 30%、Upside/ESP 20%、Surprise 10%。
- 每个模块使用四期原始向量做市场内相对百分位；期限优先级保持 Q1 → Q2 → F1 → F2，Surprise 使用 Q0 → Q-1 → Q-2 → Q-3。
- Agreement 使用 `(Up - Down) / (Up + Down)` 表示修正方向；无修正时为中性 0。
- Zacks 美股使用全部四项。Yahoo A股和港股没有 ESP 与 Surprise，只使用 Magnitude 与 Agreement，并把 40:30 的可用权重归一到 100 分。
- 单股票市场无法形成相对排名，记为中性 50 分。

## 数据流与兼容

评分由 EPS 发布脚本从当日已验证基线确定性计算，连同因子向量、分项分和数据覆盖率写入公开快照。页面只展示并按快照总分排序；旧快照没有分数时回退到既有 Magnitude 原始趋势排序，避免部署窗口出现空白或脚本错误。

评分不改变日报变化识别、趋势延续、截图标记、Gmail 发送或成功基线。

## 验收

- 发布器测试覆盖四项权重、A/H 缺失项归一、单股票市场中性分和市场隔离。
- 页面测试覆盖总分排序、分组顺序、分数徽章与缓存版本。
- 本地桌面和移动端视觉检查后，发布真实快照、部署 GitHub Pages，并核对线上 API、DOM 顺序、样式与控制台。
