# EPS 市场分组与趋势强弱排序设计

## 目标

EPS 页面把美股、A股、港股分成独立区块，不跨市场比较。每个市场内部按 `Trend of estimate revision` 的综合强度从强到弱展示，搜索和市场筛选后仍保持相同分组与排序。

## 排序口径

每只股票取 Q1、Q2、F1、F2 四项可用趋势百分比做简单算术平均。`--` 或不可解析值不参与平均；四项都不可用时综合强度为 `--`，排在该市场最后。综合强度相同则按股票代码升序，保证页面顺序稳定。

市场展示顺序固定为美股、A股、港股。港股不并入 A 股，避免不同市场与数据特征混排。

## 页面与验收

页面在每个市场区块显示股票数量和“按综合趋势由强到弱”，并在桌面端股票标签区显示可核对的综合趋势值。排序只影响展示，不修改 API 快照、邮件、成功基线、变化提醒或趋势记忆。自动测试覆盖市场分组、强弱排序、缺失值置底和静态资源加载顺序；上线后核对桌面、移动端、筛选结果和控制台。
