# EPS 市场分组与趋势强弱排序设计

## 目标

EPS 页面把美股、A股、港股分成独立区块，不跨市场比较。每个市场内部只按 `Trend of estimate revision` 的原始数值从强到弱展示，搜索和市场筛选后仍保持相同分组与排序。

## 排序口径

排序不计算平均值或综合分。先比较 Q1；Q1 相同时比较 Q2，再依次比较 F1、F2。当前比较项为 `--` 或不可解析值时排在有数值者之后；四项都相同则按股票代码升序，保证页面顺序稳定。

市场展示顺序固定为美股、A股、港股。港股不并入 A 股，避免不同市场与数据特征混排。

## 页面与验收

页面在每个市场区块显示股票数量和排序口径，不展示任何综合分。排序只影响展示，不修改 API 快照、邮件、成功基线、变化提醒或趋势记忆。自动测试覆盖市场分组、逐项优先排序、缺失值置底和静态资源加载顺序；上线后核对桌面、移动端、筛选结果和控制台。
