# Brassivo EPS 公开与自动发布设计

## 目标

`https://brassivo.com/eps/` 直接展示最近一次成功日报的脱敏结构化快照，不再要求会员登录。点击“最近真实变化”后显示该股票同一封日报里的已标注截图。工作日定时任务在 Gmail 投递、回读和本地基线更新全部成功后，自动发布并回读验收。

## 数据流

1. EPS 日报按既有规则抓取、比较、截图并发送 Gmail。
2. 只有 13 只股票全部成功、13 个附件和全部校验门槛通过，才原子更新本地成功基线。
3. 定时任务调用 `scripts/publish_brassivo_eps_auto.sh`；包装脚本从 macOS 钥匙串读取发布令牌。
4. 发布器重新校验同日日志与成功基线，并从当天输出目录精确读取邮件使用的 13 张已标注 PNG。
5. 发布器以“日期 + 股票代码 + SHA-256”作为不可变图片地址，向 Worker 的受保护图片接口逐张上传，随后从公开图片接口逐张回读并按字节核对。
6. 只有 13 张图片全部通过，才把对应 SHA-256 写入每只股票并向 `POST /admin/eps` 上传脱敏快照，再匿名读取 `GET /eps/data` 逐字段核对；同日更正也不会命中旧图或出现半新半旧的当前版本。
7. 网页每次加载直接读取公开接口；截图仅在用户展开对应股票时加载，因此无需每日重新部署静态页面，也不会首屏下载全部图片。

## 安全与失败保护

- 公开四期 EPS 估计、7 日上调/下调计数、最近真实变化、数据源、摘要，以及与当日邮件附件完全一致的已标注股票截图；不公开 Gmail 标识、本地路径、临时原图或历史原始表。
- 发布写入仍由 Cloudflare secret 保护；令牌仅存在 Cloudflare 与本机登录钥匙串，不进入 Git、自动化提示词、环境文件或日志。
- Gmail 未成功、当日数据不完整、基线日期不一致、钥匙串缺失、任一图片上传/回读失败或数据回读不一致时，发布器非零退出；结构化快照最后写入，避免不完整图片成为网页当前版本。
- 网页读取失败时显示明确错误，不回退到内嵌旧数据。

## 验收

- Worker 测试证明匿名 `GET /eps/data` 返回快照，写入仍要求发布令牌。
- 页面测试证明不存在登录表单和凭证请求，且仍无内嵌股票数据。
- 发布器测试覆盖写入后回读一致与不一致失败。
- 图片发布测试覆盖 13 张邮件附件匹配、受保护写入、公开按需读取、逐字节回读，以及图片失败时不写结构化快照。
- 项目校验检查自动发布包装脚本、钥匙串标识和定时任务提示词。
- 上线后核对 Worker、Pages、公开 API、桌面/移动端页面及 13 只股票。
