# 方块飞车（Block Kart）维护文档

方块风格卡丁车网页游戏，玩法参考卡丁车竞速：6 台车、6 圈、漂移攒火花加速、道具箱、AI 对手。
手机 / 平板 / 电脑 / 手柄均可玩。游戏前端为静态网页；账号与云端排行榜使用独立 Cloudflare Worker + D1。

## 文件
- `index.html`：游戏主逻辑（HTML+CSS+JS）
- `api.js`：云端 API 客户端；独立部署时可游客游玩
- `learning.js` / `question-bank.json`：选择题抽取与题库
- `vendor/three.min.js`：Three.js r149（本地托管，国内访问不依赖 CDN）

## 部署到自己的域名
把整个文件夹上传到任意静态托管即可：
- 国内：阿里云 OSS / 腾讯云 COS 开启静态网站托管，绑定已备案域名
- 海外：Cloudflare Pages / Vercel / GitHub Pages，直接拖文件夹
本地预览：在本目录运行 `npx serve` 或 `python -m http.server`，浏览器打开 http://localhost:8000
（普通竞速可直接打开；学霸题库需要 HTTP 服务）

## 操作
- 电脑：W/↑ 油门，S/↓ 刹车倒车，A D/← → 转向，空格 漂移，E 道具，Esc 暂停
- iPad：左下左右方向键，右下按住加速，旁边道具/刹车；没有触屏漂移按钮。手机默认重力转向（自动油门），可选左右方向键。
- 手柄：左摇杆转向，RT 油门，LT 刹车，RB 漂移，X 道具

## 常改的位置（在 index.html 里搜索）

## 性能策略
- 地形用一个合并网格（只生成可见面）一次绘制；树木、护栏用 InstancedMesh
- 画质默认流畅，可手动选择均衡或精美；旧自动选项已移除，旧自动偏好迁移为流畅
- 纹理全部用代码生成（无图片资源），整包约 700KB

## 跑车引擎音色

原创合成跑车风格引擎，叠加不均匀排气谐波、低频车身轰鸣与气流声，替换单锯齿波。6挡声学模拟：随速度升转速，升挡短暂降转速/减弱排气，降挡补油；倒数时空挡轰油，不提前升挡。声学模型不改变实际驾驶/速度参数。HUD显示挡位与转速，已有总声音开关、暂停/答题/后台静音兼容。风格参考运动型跑车，不是玛莎拉蒂实车录音。

换挡视觉效果：升挡从双排气口喷出橙黄火焰及火花，降挡较轻；每次换挡单次触发，粒子0.18–0.4秒淡出。声学挡位独立于音频输出计算，静音/无AudioContext仍有火花及挡位显示；不改变道具或驾驶能力。

最高前进车速为200 KM/H：极速档最快角色正常行驶最高170，起步/火箭加速可到200；其他难度和角色保留差异。

休息锁定界面可展开“管理员解除休息”，验证指定密码后取消本次锁定并重新累计30分钟；不永久关闭休息规则。比赛仍通过原来的暂停/答题界面继续，避免突然恢复驾驶。此入口仅用于本机休息控制，与云端账号或管理权限无关。
