# 方块飞车（Block Kart）维护文档

方块风格卡丁车网页游戏，玩法参考卡丁车竞速：6 台车、3 圈、漂移攒火花加速、道具箱、AI 对手。
手机 / 平板 / 电脑 / 手柄均可玩。游戏前端为静态网页；账号与云端排行榜使用独立 Cloudflare Worker + D1。

## 文件
- `index.html`：游戏主逻辑（HTML+CSS+JS）
- `api.js`：云端 API 客户端；独立部署时可游客游玩
- `learning.js` / `question-bank.json`：选择题抽取与题库
- `vendor/three.min.js`：Three.js r149（本地托管，国内访问不依赖 CDN）

## 部署到自己的域名
把整个文件夹上传到任意静态托管即可：
- 国内：阿里云 OSS / 腾讯云 COS 开启静态网站托管，绑定已备案域名
- 海外：Cloudflare Pages / Vercel / GitHub Pages，直接拖文件夹
本地预览：在本目录运行 `npx serve` 或 `python -m http.server`，浏览器打开 http://localhost:8000
（普通竞速可直接打开；学霸题库需要 HTTP 服务）

## 操作
- 电脑：W/↑ 油门，S/↓ 刹车倒车，A D/← → 转向，空格 漂移，E 道具，P 暂停
- 触屏：左半屏拖动转向（自动油门，往下拖=刹车），右侧 漂移/道具/刹车
- 手柄：左摇杆转向，RT 油门，LT 刹车，RB 漂移，X 道具

## 常改的位置（在 index.html 里搜索）
| 想改什么 | 搜索 | 说明 |
|---|---|---|
| 圈数、车速、加速度 | `const B = 3, ROAD` | LAPS 圈数，BASE 极速，ACC 加速 |
| 新增/修改赛道 | `const TRACKS` | pts 为赛道控制点（绕中心按角度顺序排列，避免自交），col 为配色，deco 为装饰树种 |
| 新增/修改车手 | `const CHARS` | 颜色、属性（spd/acc/hnd/w）、头部装饰 extra |
| 难度与 AI 强度 | `const DIFFS` | scale 全局速度，ai 为 AI 速度系数 |
| 道具概率 | `function pickItem` | 名次越靠后越容易拿到火箭/追踪弹 |
| 道具效果 | `function useItem` | turbo/jelly/missile |
| 画质档位 | `const QCFG` | 分辨率倍率、阴影尺寸、树木密度、雾距 |
| 漂移手感 | `if (k.drifting)` | 火花等级阈值 0.75/1.6/2.6 秒，加速时长 0.55/0.95/1.4 秒 |

## 性能策略
- 地形用一个合并网格（只生成可见面）一次绘制；树木、护栏用 InstancedMesh
- 画质默认流畅，可手动选择均衡或精美；旧自动选项已移除，旧自动偏好迁移为流畅
- 纹理全部用代码生成（无图片资源），整包约 700KB

## 2026-10-02 在线与学霸 MVP
- `/game/` 注册账号、登录、查看云端成绩和排行榜；游客仍可玩。登录后的比赛需取得服务端 runId，完赛提交一次。
- 学霸模式默认关闭，年级1–6，题库默认综合、科目随年级筛选；可以指定数学、语文、英语及其他科目。每题四选一；每圈经过终点线答题，全场暂停；答对追加3个随机道具，答错追加1个，不施加旋转惩罚；道具排队存储，使用一个切到下一个，HUD显示剩余数量。路上盲盒在学霸模式隐藏且不参与碰撞，普通模式保留。第三圈答题完成后结算。
- 首版408道原创入门练习，非官方浙江题库；英语与信息科技从三年级起提供，年级难度分组不代表学校进度。课程框架参考教育部2022课程方案。
- 排行榜按赛道、难度、模式、年级、科目分组，每人最好用时，展示答题正确率。普通模式与学霸模式分开，本机成绩也按题库设置区分。
- API为独立Cloudflare Worker，D1存账号/会话/比赛/成绩；密码PBKDF2，HttpOnly会话Cookie、来源校验、基础限流和重复提交防护。MVP暂不支持找回密码、邮箱/微信/短信登录。社区榜为客户端计时，基础校验不等于严格防作弊。

- 2026-10-02：首次游玩默认标准，已保存难度保留。移除浙江地方知识；一二年级隐藏英语、信息科技，综合随机也不抽这些科目。

- 题库每个可选年级/单科至少6题，按分类一轮不重复，下一轮首题避开上轮末题；每次独立打乱四个答案位置。

- 触屏默认重力转向，可在菜单/暂停中切换模拟摇杆及校准中心；HTTPS下由开始按钮触发设备授权，未授权或未收到传感器数据时本场回退摇杆。横竖屏变化重新校准，默认保留流畅画质与标准难度。传感器仅本地用于转向，不上传。
